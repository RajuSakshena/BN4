- heat_exposure_index_0_100: Synthetic index value from 0 to 100; higher values indicate higher illustrative exposure.
- plan_readiness_index_0_100: Synthetic index value from 0 to 100; higher values indicate stronger illustrative readiness.
- cooling_access_index_0_100: Synthetic index value from 0 to 100; higher values indicate better illustrative access.
