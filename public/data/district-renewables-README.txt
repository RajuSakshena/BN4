BHARATNOMY DATA PROTOTYPE
Dataset: District Renewable Capacity Snapshot
Identifier: BN-ENR-002
Version: 0.1 prototype
Created: November 2026
Geography: Selected districts, Maharashtra, India
Format: CSV (UTF-8)

IMPORTANT DATA NOTICE
All values in this file are synthetic demonstration values created only to demonstrate the Bharatnomy website interface. They are NOT official statistics, measured observations, verified estimates, research results, or published Bharatnomy findings. Do not cite, reuse as evidence, or make decisions based on these values.

PURPOSE
Demonstrates a possible asset/capacity-oriented energy dataset with separate solar and wind capacity fields. The values and units are illustrative and do not represent actual installed capacity.

COLUMNS
- district: District label used in the prototype.
- state: State label.
- solar_capacity_illustrative_gw: Synthetic solar capacity value in illustrative GW.
- wind_capacity_illustrative_gw: Synthetic wind capacity value in illustrative GW.
- total_renewable_capacity_illustrative_gw: Sum of the synthetic solar and wind values in illustrative GW.
- data_status: Explicit marker that the row is synthetic demonstration data.

METHODOLOGY
No official asset registry, generation statistics, field survey, or government extract underpins these figures. Values were authored for interface prototyping and must not be treated as actual capacity.

GEOGRAPHIC LIMITATION
The interface's map is a schematic visual locator, not a GIS boundary file. It does not represent accurate district polygons, distances, areas, or coordinates.

SOURCE / PROVENANCE
Source: Bharatnomy website prototype (synthetic data authored for UI demonstration).
Collection date: Not applicable; no external data was collected.

LICENSE / REUSE
Do not redistribute as official Bharatnomy data or present as empirical evidence. Replace this file with verified, documented observations before any public data release.
