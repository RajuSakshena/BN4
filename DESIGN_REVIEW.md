# Design Review — Three New Bharatnomy Formats

These three formats deliberately change the information architecture, not just the palette. They all use light surfaces, a visible grid system and restrained movement, but each puts navigation and content in a different place.

| Format | Navigation location | Homepage composition | Canvas / visual system | Suggested use |
|---|---|---|---|---|
| 01 — Field Grid | Fixed left research sidebar | Oversized typographic headline, then a wide cartographic field canvas and five-column research index | Lichen/sage, technical grid, contour lines, signal rings and moving locator | Strong all-round research institution with quick access to sections |
| 02 — Signal Observatory | Fixed right-edge vertical rail | Centered statement, coordinates, wide 3D signal instrument, transmission strip and indicator band | Ice blue, cobalt, vermilion accents, animated orbital plane and floating nodes | Distinctive data observatory / product-led identity |
| 03 — Research Ledger | Fixed bottom navigation dock | Large folio-style headline, side index, full-width illustrated landscape, numbered editorial rows | Warm paper, terracotta, muted olive, fine printed-paper grid and layered animated landscape | Editorial, publication-led and highly typographic identity |

## Structural differences

- Navigation is deliberately relocated to the left, right edge and bottom dock, respectively.
- None of the three uses the earlier top-tab navigation or the same side-by-side text/photo hero.
- The opening visual changes from a spatial field map, to a 3D observatory instrument, to a full-width landscape/folio composition.
- Each format uses a separate typographic pairing, palette, grid treatment and motion rhythm.
- A floating **Format Study** review control switches between the three prototypes. It is a temporary decision-making aid, not part of the final public website.

## Content included

The prototype carries over the supplied HTML's research identity and five lenses, current research status, Maharashtra Heat Action Plans project and status milestones, research outputs and topic-selection criteria, dataset development and release rules, state profile plan, audience, team, editorial standards, non-negotiables, trade-offs, corrections, funding transparency and careers information.

## Suggested review sequence

1. Compare the first screen at the same desktop width and note the position of the navigation.
2. Scroll through Research, Datasets and Data Observatory to assess dense-information readability.
3. Use the Format Study switcher to compare each structure without changing project files.
4. Test the two data demonstrators: change dataset, indicator, district and Map / Chart / Table view; test the CSV and README downloads.
5. Check the mobile layout, where side navigation becomes a compact bar and the bottom dock remains accessible.
6. Select the structural direction first; refine logo, brand colours and imagery only after the team agrees on the format.
